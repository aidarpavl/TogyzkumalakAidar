# ⚫⚪ Ұлттық ойындар / Национальные игры

**Тоғызқұмалақ · Асық ату · Дойбы · Жамбы ату · Қыз қуу · Теңге алу · Көкпар · Аударыспақ** — Streamlit-тегі онлайн портал / онлайн-портал на Streamlit.

## Мүмкіндіктер / Возможности

| | Қазақша | Русский |
|---|---|---|
| 🏠 | Басты бет: суреттер + 3 ойын батырмасы | Главная: картинки + 3 кнопки игр |
| ⚫ | **Тоғызқұмалақ**: түздық, талдау, күнделікті есептер | **Тогызкумалак**: туздык, анализ, ежедневные задачи |
| 🦴 | **Асық ату**: физикасы бар ату, сақаны тартып жіберу, асық иіру | **Асык ату**: удар с физикой, оттянуть саку и отпустить, бросок асыка |
| ♛ | **Дойбы**: орыс 8×8 және халықаралық 10×10, міндетті соғу, дамка | **Дойбы**: русские 8×8 и международные 10×10, обязательное взятие, дамки |
| 🏹 | **Жамбы ату**: аттан садақ ату — галоп тербелісі (амортизация), жел, 30/50/70 м, 3 серия × 3 оқ | **Жамбы ату**: стрельба из лука на скаку — тряска галопа (амортизация), ветер, 30/50/70 м, 3 серии × 3 стрелы |
| 🐎 | **Қыз қуу**: рөл таңдау (қыз/жігіт), 2 кезең, 3 экран (бүйір/алды/арты), атты жетілдіру +5% (100 ₸, QR), жеңіс бонусы +5%/+10% | **Кыз куу**: выбор роли, 2 этапа, 3 экрана (сбоку/спереди/сзади), прокачка коня +5% (100 ₸, QR), бонус за победу +5%/+10% |
| 🪙 | **Теңге алу**: 150 м, 5 орамал сол/оң, еңкею (СОЛҒА/ОҢҒА), айыппұл +2 с, 3 экран, жетілдіру: жылдамдық/шыдамдылық/дәлдік | **Тенге алу**: 150 м, 5 платков слева/справа, наклон, штраф +2 с, 3 экрана, прокачка: скорость/выносливость/точность |
| 🐐 | **Көкпар**: 3 × 3, серкені ілу, тартыс (жиі басу), қазанға салу, 3 кезең + алтын гол, 3D 3 экран, джойстик; ат (жылдамдық/үдеу/шыдамдылық) және шабандоз (күш/ептілік) жетілдіру | **Кокпар**: 3 × 3, подъём серке, тартыс (частые нажатия), гол в казан, 3 периода + золотой гол, 3D 3 экрана, джойстик; прокачка коня (скорость/ускорение/выносливость) и всадника (сила/ловкость) |
| 🤼 | **Аударыспақ**: ат үстінде күрес, 40 м шеңбер, ТАРТУ/ИТЕРУ/БҰРУ (тас-қайшы-қағаз) + ТЕПЕ-ТЕҢДІК + айналып кету, 3 раундтың 2-уі, 3D 3 экран, құлау анимациясы; ат (орнықтылық/бұрылу/шыдамдылық) және шабандоз (күш/хват/тепе-теңдік) жетілдіру | **Аударыспак**: борьба на конях, круг 40 м, ТЯНУТЬ/ТОЛКАТЬ/СКРУТКА (камень-ножницы-бумага) + РАВНОВЕСИЕ + разворот, до 2 побед из 3 раундов, 3D 3 экрана, анимация падения; прокачка коня (устойчивость/манёвренность/выносливость) и всадника (сила/хват/равновесие) |
| 🤖 | Әр ойында ИИ: 4 деңгей + нейрожелі (API кілті барлық ойынға ортақ) | ИИ в каждой игре: 4 уровня + нейросеть (один API-ключ для всех игр) |
| 🌐 | Онлайн бөлмелер, шақыру сілтемесі, сағат, чат, көрермен | Онлайн-комнаты, ссылка-приглашение, часы, чат, зрители |
| 🏆 | Әр ойынға жеке Elo рейтингі + чемпионат көшбасшылары | Отдельный рейтинг Эло по каждой игре + лидеры чемпионата |
| 🏅 | Чемпионат: Kaspi QR → 3 әрекет, жеңіліс −1, жеңіс +1…+4 ұпай | Чемпионат: Kaspi QR → 3 попытки, поражение −1, победа +1…+4 балла |
| 💸 | Жүлде қоры 30%, 1000 ұпайдан Kaspi нөміріне шығару (әкімші арқылы) | Призовой фонд 30%, вывод от 1000 баллов на Kaspi (через админа) |
| 🛠 | Әкімші панелі: төлемді растау, шығару, QR, баға | Админ-панель: подтверждение оплат, выплаты, QR, цена |
| 🇰🇿🇷🇺 📱 | Екі тіл, мобильді нұсқа | Два языка, мобильная версия |

## Іске қосу / Запуск

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Streamlit Cloud

1. Репозиторийді GitHub-қа жүктеңіз → https://share.streamlit.io → **New app** → `app.py`.
2. **Settings → Secrets** (`.streamlit/secrets.toml.example` қараңыз):
   ```toml
   DATABASE_URL = "postgresql://postgres.bhewmxuazlmigaesovjq:ПАРОЛЬ@aws-0-ap-south-1.pooler.supabase.com:5432/postgres?sslmode=require"
   ADMIN_USERS = "aidarpavl"
   ```
3. Сайтта **aidarpavl** атымен тіркеліңіз → «🛠 Әкімші» → Kaspi QR суретін жүктеңіз.
   Зарегистрируйтесь на сайте как **aidarpavl** → «🛠 Админ» → загрузите изображение Kaspi QR.

Кестелер іске қосылғанда автоматты түрде жасалады (`supabase_schema.sql` — қолмен орындауға).
Таблицы создаются автоматически при запуске (`supabase_schema.sql` — для ручного запуска).

## Құрылымы / Структура

```
app.py                      — навигация
ui/pages.py                 — басты бет, кіру, рейтинг, профиль, баптаулар, чемпионат, әкімші
ui/play.py                  — ИИ / онлайн / бір құрылғыда (үш ойынға ортақ)
ui/specs.py                 — ойындардың сипаттамасы
ui/togyz_extra.py           — тоғызқұмалақ талдауы мен есептері
core/engine.py              — тоғызқұмалақ ережелері + ИИ
core/asyk.py                — асық ату физикасы + ИИ
core/draughts.py            — дойбы ережелері + ИИ
core/jamby.py               — жамбы ату: шабыс, тербеліс, жел, ұпай + ИИ
core/kyzkuu.py              — қыз қуу: жарыс моделі (JS-пен бірдей), ат көрсеткіштері + ИИ
core/tenge.py               — теңге алу: шабыс, еңкею, айыппұл + ИИ
core/kokpar.py              — көкпар: 3×3 детерминистік модель (JS-пен бірдей), тартыс, ИИ
core/audaryspak.py          — аударыспақ: күрес моделі (JS-пен бірдей), 4 деңгейлі ИИ
core/db.py                  — SQLite / PostgreSQL (Supabase)
core/llm.py                 — нейрожелі провайдерлері
core/i18n.py                — қазақша / орысша
components/{board,asyk,draughts,jamby,kyzkuu,tenge,kokpar,audaryspak}/index.html
components/_shared/          — 3D қозғалтқыш (gl3d.js) және көкпар модельдерінің бастапқы коды — интерактивті тақталар
assets/                     — басты бет суреттері
```
