# ⚫⚪ Тоғызқұмалақ онлайн / Тогызкумалак онлайн

Қазақтың ұлттық зияткерлік ойыны — Streamlit-тегі толық онлайн нұсқа.
Казахская национальная интеллектуальная игра: полноценная онлайн-версия на Streamlit.

## Мүмкіндіктер / Возможности

| | Қазақша | Русский |
|---|---|---|
| 🌐 | Нақты ойыншылармен онлайн: бөлмелер, код/сілтеме арқылы шақыру, көрермен режимі, чат | Онлайн с реальными игроками: комнаты, приглашение по коду/ссылке, режим зрителя, чат |

| 🏆 | Elo рейтингі, подиум, жеңіс пайызы, ең жоғары рейтинг | Рейтинг Эло, подиум, % побед, пиковый рейтинг |

## Іске қосу / Запуск

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Streamlit Cloud-қа орналастыру / Деплой на Streamlit Cloud

1. Репозиторийді GitHub-қа жүктеңіз / Загрузите репозиторий на GitHub.
2. https://share.streamlit.io → **New app** → репозиторий, `main`, `app.py`.
3. **Маңызды / Важно:** Streamlit Cloud-та файлдар қайта іске қосқанда өшеді. Рейтинг сақталуы үшін тегін PostgreSQL ([Supabase](https://supabase.com) немесе [Neon](https://neon.tech)) жасап, **Settings → Secrets** ішіне қосыңыз:
   На Streamlit Cloud файлы стираются при перезапуске. Чтобы рейтинг сохранялся, создайте бесплатный PostgreSQL и добавьте в **Settings → Secrets**:
   ```toml
   DATABASE_URL = "postgresql://user:password@host:5432/db?sslmode=require"
   ```
   `DATABASE_URL` берілмесе, SQLite (`togyz.db`) қолданылады. Без `DATABASE_URL` используется SQLite (`togyz.db`).

## Құрылымы / Структура

```
app.py                      — интерфейс (Streamlit)
core/engine.py              — ережелер, ИИ (minimax + alpha-beta), талдау, есептер
core/db.py                  — пайдаланушылар, бөлмелер, Elo, чат (SQLite / PostgreSQL)
core/llm.py                 — нейрожелі провайдерлері
core/i18n.py                — қазақша / орысша мәтіндер, ережелер
components/board/index.html — интерактивті тақта (HTML/JS компонент)
```

## Нотация

`73x`: ход из 7-й лунки, последний кумалак упал в 3-ю лунку соперника; `x` — взятие, `X` — туздык.
